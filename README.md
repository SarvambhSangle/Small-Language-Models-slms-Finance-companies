# Financial Analysis using Small Language Models (SLMs)

This project demonstrates the application of **Natural Language Processing (NLP)** and **Small Language Models** to automate the extraction of key insights from lengthy corporate annual reports. By processing complex financial documents, the system creates meaningful visualizations that summarize business performance and strategic focus areas.

O) 🚀 Overview
Analyzing annual reports like the **NYSE Finance of America Companies** or **SBI Annual Bank Report** manually is time-consuming. This project provides a framework to programmatically parse these PDFs, identify critical data points, and visualize the company's trajectory.

K) ✨ Key Features
* **Automated Data Extraction:** Uses NLP techniques to scan and retrieve insights from high-volume financial PDFs.
* **Multi-Institution Support:** Validated against diverse reports, including the NYSE_FOA_2024 and SBI annual reports.
* **Data Visualization:** Transforms raw text and tabular data into summarized visual representations of performance.
* **Domain-Specific Analysis:** Tailored for the financial sector to handle specialized terminology and reporting standards.

P) 📁 Project Structure
* **`Finance of America Companies.ipynb`**: Core logic for processing NYSE-specific filings.
* **`Main SBI .ipynb`**: Implementation for analyzing State Bank of India reports.
* **`NYSE_FOA_2024 (1).pdf` / `SBI annual Bank report.pdf`**: Source datasets for the analytical pipeline.
* **`README.md`**: Project documentation.

T) 🛠️ Tech Stack
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Key Libraries:** PyPDF2/PDFMiner (for extraction), NLTK/Spacy (for NLP), Matplotlib/Seaborn (for visualization).

F) 📈 Future Enhancements
* **Sentiment Analysis:** Evaluating the "tone" of executive summaries to predict market outlook.
* **Comparative Analytics:** Side-by-side performance tracking against industry competitors.
* **Temporal Tracking:** Analyzing shifts in business focus over multiple fiscal years.
